Contenido por LLM

Cada topic puede tener su contenido generado por LLM (Groq) basado en su título y descripción. El contenido generado se renderiza con el mismo formato SAAC que el contenido hand-crafted.

Tokens de Sofi

Cada token autoriza un dispositivo. Por ahora se crea desde la consola del navegador. 

fetch('/api/admin/sofi-tokens', {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify({ device_name: 'Laptop personal' }),
  credentials: 'include'
}).then(r => r.json()).then(console.log)
